# iozhik

Scrapes the Telegram Bot API docs into a DSL (`tgbot.api`) and generates telegramium-core from it.

The Bot API terms (Method, Payload, Attachment, Embedded file, Wire request, Omitted vs empty, Unknown update) are defined in [telegramium's GLOSSARY.md](https://github.com/apimorphism/telegramium/blob/master/GLOSSARY.md), which is the source of truth for them.
